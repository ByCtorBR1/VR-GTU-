# 🏫 Recorrido Virtual - GTU Campus Toluca

> Aplicación web desarrollada como sitio informativo y recorrido virtual para el Grupo Tecnológico Universitario (Campus Toluca), permitiendo a los futuros estudiantes conocer de forma remota las instalaciones, oferta educativa y detalles de la institución.

## 🔗 Enlace en Vivo
[👉 Probar aplicación en línea](https://vrgtu.netlify.app/)

## 🛠️ Tecnologías Utilizadas
* **HTML5** (Estructura semántica y organización multipágina)
* **CSS3** (Estilos personalizados y diseño responsivo)
* **Netlify** (Despliegue y hosting continuo)

## ✨ Características Principales
* **Navegación Interactiva:** Estructura organizada por pisos y secciones del campus para un recorrido inmersivo.
* **Sección de Preguntas Frecuentes (FAQ):** Información clave sobre validez oficial (RVOE), oferta educativa y colegiaturas.
* **Canales de Contacto Directo:** Integración con enlaces rápidos a redes sociales (Facebook, Instagram) y conexión directa a WhatsApp de atención a admisiones.
* **Geolocalización:** Inclusión de referencias de ubicación física en Toluca de Lerdo.
